### Correction of the inherited disposition

Phase157's notes recorded "43 = 23 hash + 18 git + 2 live-`.env` guard",
measured in its build worktree. Two corrections, both evidence-based:

* one test that shells out to `git grep`
  (`test_upstream_hypothesis_audit.py::…::test_only_coercion_constructs_records_in_core`)
  had been counted as a hash failure; it is a Git fact. Hence **22 hash + 19 Git**,
  not 23 + 18.
* the 2 live-`.env` failures are packaging-hygiene assertions that fire only in a
  worktree that *holds* `.env`. In the clean workspace they pass, and a different
  one-off appears instead (the nesting artifact above). So the worktree count is
  43 = 22 + 19 + 2, and the clean-workspace count is 42 = 22 + 19 + 1.

This matters: counting a `git grep` test as a hash failure sends a repair hunting
for a digest that was never the cause.
